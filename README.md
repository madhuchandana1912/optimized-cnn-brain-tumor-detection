# optimized-cnn-brain-tumor-detection
CNN-based brain tumor detection using MRI images.
Optimized CNN Model for Early Detection of Brain Tumor Using MRI Scans

## Project Overview
This project uses a Convolutional Neural Network (CNN) to detect
brain tumors from MRI images.

## Technologies Used
- Python
- TensorFlow
- Keras
- OpenCV
- NumPy
- Google Colab

## Methodology
1. Collect MRI images
2. Preprocess the images
3. Resize and normalize images
4. Split data into training and testing sets
5. Train the CNN model
6. Evaluate the model
7. Predict tumor and non-tumor MRI images

## Project Outcome
The CNN model is designed to assist in the early classification
of brain MRI images into tumor and non-tumor categories.
